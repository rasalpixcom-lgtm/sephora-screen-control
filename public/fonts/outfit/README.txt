Outfit PDF fonts

Source: https://github.com/google/fonts/tree/main/ofl/outfit
License: SIL Open Font License 1.1 (see OFL.txt).

Outfit-Regular.ttf and Outfit-SemiBold.ttf are static instances of the
upstream Outfit[wght].ttf at weights 400 and 600, generated with FontTools.
These assets are bundled for screen details PDF exports on Windows and Linux.
